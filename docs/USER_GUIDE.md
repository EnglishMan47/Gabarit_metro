# Руководство пользователя

«Габарит» показывает облако бортового лидара, оценённый путь и обнаруженные препятствия. Для запуска используйте [INSTALLATION.md](INSTALLATION.md), для текущих численных результатов — [отчёт от 12 ноября](VALIDATION_2026_11_12.md).

## Начало работы

1. Запустите `python -m gabarit web --data <каталог-записей>` в установленной среде и откройте [localhost:8000](http://localhost:8000). В Docker live-интерфейс находится на [localhost:8080](http://localhost:8080).
2. Выберите запись. Каталог может содержать несколько частей SQLite bag; они должны оставаться вместе.
3. Выберите профиль координат. Для `falcon_test_second_dark` — Falcon Prime ROS; для исходных Pandar и `new_data` — Pandar. Примените настройки.
4. Нажмите пуск. Для проверки отдельного места используйте паузу, перемотку и покадровые кнопки.

## Значения состояния

| Состояние | Смысл |
|---|---|
| Путь свободен | нет подтверждённого препятствия в текущем наблюдаемом коридоре; указан ограниченный свежими измерениями горизонт |
| Проверка объекта | кандидат ожидает необходимой временной поддержки |
| Препятствие | алгоритм подтвердил трек; показаны расстояние, положение и размер |
| Недостаточно данных | опоры пути ненадёжны или отсутствуют; отсутствие тревоги не доказывает свободный путь |
| Потеря потока | просмотрщик не получает свежие сообщения; предыдущее состояние не является новым измерением |

Удержанный габарит помогает читать сцену между наблюдениями. Его дальность может быть больше свежей наблюдаемой дальности, но не продлевает проверенный свободный путь. Предельные 200 м Pandar и 350 м Falcon — границы анализа, а не гарантированная дальность обнаружения каждого объекта.

## Просмотр и объекты

Камеры переключаются клавишами 1–6: кабина, сзади, сверху, сбоку, к цели и свободный обзор. Щелчок по объекту выбирает цель; соответствующие бокс и карточка выделяются. В карточке доступны расстояние, размеры, число точек и лучей, первое обнаружение и подтверждение. Оценка confidence не является сертифицированной вероятностью безопасности.

Пробел управляет пуском и паузой, стрелки — покадровым просмотром. Пауза и множитель скорости относятся к воспроизведению: тревога их автоматически не изменяет. Подтверждение препятствия выполняется алгоритмом, ответ оператора не запрашивается.

Вкладка «Вид» управляет облаком, габаритом, рамками, цветом и подписями. Светлая и тёмная темы переключаются в верхней строке. «Детектор» изменяет габарит и чувствительность; для сравнения результатов сохраните использованные параметры. «Скорость» показывает времена этапов, которые следует отличать от задержки доставки и рисования.

## Анализ записи и испытательные объекты

«Анализ всего проезда» обрабатывает кадры по порядку и строит таймлайн событий. Нажатие на событие перематывает к нему. Результаты анализа кешируются с учётом записи и конфигурации.

Во вкладке «Испытание» можно вставить виртуальный объект на заданной дальности или использовать Shift и щелчок по коридору. Вставка производится трассировкой лучей с перекрытием фона; это испытание алгоритма на моделируемом объекте, а не независимая разметка реального проезда.

## Live и администрирование

В live-режиме кадрами управляет ROS-источник; просмотрщик получает последние результаты. Медленный браузер может пропускать промежуточные кадры отображения. Для диагностики потери входных облаков используйте внешний ROS-бенчмарк.

Загрузка своей записи поддерживает `.db3`, `.zip` и `.tar`. По умолчанию воспроизведение допускает одного пользователя; лимит задаёт `--max-users`. Панель `/admin` управляет записями, параметрами, версиями и сеансами. Логин `admin`, пароль задаётся `GABARIT_ADMIN_PASSWORD`, значение по умолчанию `admin`. Необязательный MLflow устанавливается через `requirements-mlops.txt`.

В машинном режиме `python -m gabarit run <bag> --jsonl result.jsonl` сохраняет решения по кадрам. [Схема результата](RESULT_FORMAT.md), [подробности интерфейса](WEB_UI.md), [системы координат](SENSORS.md).
