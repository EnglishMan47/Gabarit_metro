# Локальное веб-приложение

Приложение напрямую читает ROS 2 SQLite3 bag, но не требует установленного ROS. CDR-сообщения `PointCloud2` декодируются локальным Python-кодом.

## Запуск

Первичная установка:

```powershell
.\scripts\setup_web.ps1
```

Запуск из PowerShell в каталоге проекта:

```powershell
.\scripts\run_web.ps1
```

Затем открыть `http://127.0.0.1:8000`.

Другой каталог данных или порт:

```powershell
.\scripts\run_web.ps1 -DataRoot "D:\lidar\for_hackathon" -Port 8080
```

Требуются Python 3.11+ и NumPy. Текущая локальная `.venv` уже настроена. ONNX Runtime необязателен: без него приложение запускается в геометрическом режиме.

## Возможности

- автоматическое обнаружение всех `.db3` внутри каталога данных;
- выбор записи и кадра;
- покадровая обработка и воспроизведение;
- интерактивная Three.js-сцена с вращением, масштабом, облаком, рельсами, габаритом и bbox, а также профиль облака;
- бинарная передача точек как `Float32Array` с JSON-заголовком;
- режимы Auto/GPU/CPU/Geometry и показ фактического ONNX-backend, задержки и причины fallback;
- настройка ширины/центра габарита, резервного пола и дальности;
- локальный профиль пола, рельсовая геометрия и коридор по дальности;
- сырой кандидат и подтверждённое временное событие;
- ближайшее расстояние, bbox, список объектов, треки и причины фильтрации;
- подтверждение или отклонение тревоги оператором;
- локальный журнал `artifacts/operator_feedback.jsonl`;
- экспорт журнала из интерфейса в JSON или CSV;
- отмена устаревшего HTTP-запроса при быстром переходе по кадрам.

## Данные и журнал

Сервер рекурсивно находит `.db3` в каталоге `-DataRoot`. В интерфейсе показываются имя записи, число кадров и длительность. В Git передаётся код и модель нормальной сцены, но не исходный датасет и не рабочий журнал оператора.

Кнопки «Подтвердить» и «Отклонить» не меняют автоматический результат: они добавляют независимую запись решения оператора. «Очистить экран» очищает видимый список, но не удаляет журнал. Для выгрузки используйте ссылки JSON и CSV.

## Проверка

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
.\.venv\Scripts\python.exe -m py_compile webapp\config.py webapp\detector.py webapp\tracking.py webapp\bag_store.py webapp\server.py
```

Проверка качества на всех кадрах выполняется `python scripts/evaluate_detector.py --step 1`. Актуальные измерения приведены в `docs/EVALUATION.md`.
