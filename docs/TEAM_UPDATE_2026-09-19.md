# Предложения команды от 19.09.2026

Источник: `Заметики по хакатону.txt`. Текст рассматривается как набор идей команды, а не как официальное изменение ТЗ.

| Предложение | Решение | Причина |
|---|---|---|
| Заменить Docker веб-интерфейсом | Принято после нового указания организаторов | Новое уточнение отменяет прежнюю обязательность Docker и ROS |
| Проанализировать готовое китайское LiDAR-решение через Kaggle | Добавить ограниченный этап исследования GitHub/Gitee/Kaggle | Нет конкретной ссылки; требуется проверка лицензии, входа и воспроизводимости |
| Документация по изученным репозиториям | Добавить таблицу источников, применённых идей и лицензий | Позволяет обосновать архитектуру и избежать неконтролируемого копирования |
| Добавить характеристики лидара | Принято | В проект добавлено руководство Pandar128E3X |
| Показывать решение вживую вместо одной accuracy | Принято | Соответствует требованию демонстрации облака, объекта и расстояния |
| Оператор подтверждает обнаружение | Принято как журнал обратной связи | Подтверждение не должно задерживать или подменять автоматическую тревогу |
| Добавить интересные функции интерфейса | Принято с разделением P1/P2 | Основной экран обязателен, декоративные и экспериментальные функции выполняются после baseline |

Плановые решения отражены в `PROJECT_PLAN.md` и `DEVELOPMENT_PLAN.md`. Первоначальная классификация предложения пересмотрена после получения более нового официального требования.
