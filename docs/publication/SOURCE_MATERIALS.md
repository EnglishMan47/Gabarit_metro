# Использованные материалы проекта

Каркас собран из ранее подготовленных материалов, с приоритетом текущих исходников и последних проверяемых результатов.

| Материал | Использование в каркасе |
|---|---|
| Техническая документация Габарит, ранее подготовленный Word-документ | исходная постановка, объяснение геометрической цепочки, интерфейсы |
| Анализ конкурентов и развитие Габарита, локальный Word-документ | идеи интеграции, происхождение моделей, риски сравнения и псевдоразметки |
| [Архитектура](../ARCHITECTURE.md), [алгоритм](../ALGORITHM.md), текущий код | описание реально реализованного метода |
| [Литература](../RELATED_WORK.md) и новые первичные публикации | обзор и выбор образца |
| [Исторические эксперименты](../EXPERIMENTS.md), отчёты 19 октября и 7 ноября | история решений; старые числа не используются как текущие |
| [Сводка проверки 12 ноября](../VALIDATION_2026_11_12.md) | существующие таблицы результатов и пределы выводов |
| `training/component_forest_v1.metrics.json`, `component_forest_v1.temporal.json` | разделения обучения, компонентные показатели, preliminary temporal-эффект |
| Расшифровка встречи 7 ноября | срок черновика 13 ноября и содержание обсуждения архитектуры |
| План С1 и общий план С1–С4, локальные материалы планирования | будущая программа экспериментов; запланированные результаты не выдаются за выполненные |

Локальные записи встреч, сырые bag, частная переписка и полный сторонний PDF не копируются в пакет статьи. Внешние материалы цитируются по первоисточнику; их наличие в обзоре не означает права на распространение самих файлов.
