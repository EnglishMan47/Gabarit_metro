# Ограничения текущей версии

## Данные

- Проверка выполнена на шести предоставленных bag общей длительностью около 250 секунд. Это мало для доказательства работы во всех тоннелях, погодных условиях и режимах движения.
- Разметка положительного bag является предварительной инженерной разметкой команды. Кандидат предмета около 76,7 м визуально устойчив, но его класс организаторами не подтверждён.
- Пять остальных bag считаются штатными по именам и контексту задачи; исчерпывающей покадровой эталонной разметки для них нет.
- Время кадров берётся из bag. Скорость поезда и точная поза лидара отсутствуют, поэтому задержка в метрах при 85 км/ч может быть только расчётной оценкой.

## Алгоритм

- Рельсовый центр применяется консервативно и ограничен смещением 0,25 м. На резком повороте используется резервный фиксированный центр.
- Модель нормы объединяет разные штатные маршруты без точной локализации; редкие конструкции могут быть приняты за препятствие.
- Текущая версия сохраняет полную полноту положительной разметки, но превышает внутреннюю цель по ложным устойчивым событиям на штатных bag. Перечень и частота приведены в `docs/EVALUATION.md`.
- Связь треков основана на близости центров в последовательных кадрах. Перекрывающиеся объекты могут обменяться идентификаторами.
- Расстояние измеряется до ближайшей видимой точки кластера, а не до физического центра объекта.

## Эксплуатация

- Решение является демонстрационным прототипом хакатона и не прошло сертификацию для управления движением.
- Веб-сервер рассчитан на локальную работу. Вкладки получают отдельные трекеры (до 16 сессий); вычислительная обработка сериализована для ограничения памяти.
- Установка зависимостей требует доступа к пакету NumPy; после установки приложение работает без интернета.
