# Проверка установки 20.09.2026

Проверено отдельное чистое окружение Python 3.11.8 / NumPy 2.4.6. Рабочая `.venv` не изменялась.

## Повторение автономной установки

На компьютере с интернетом загрузить wheel для нужной версии Python и Windows:

```powershell
python -m pip download --index-url https://pypi.org/simple --only-binary=:all: --dest artifacts/wheels -r requirements.txt
```

Затем установка из этих файлов без сети:

```powershell
.\scripts\setup_web.ps1 -PythonCommand python -EnvironmentDirectory artifacts/clean-venv -WheelDirectory artifacts/wheels
.\artifacts\clean-venv\Scripts\python.exe -m unittest discover -s tests -v
.\artifacts\clean-venv\Scripts\python.exe -m webapp.server --port 8001
```

Wheel зависит от версии Python, архитектуры и ОС; пакет для Python 3.11 Windows нельзя использовать для другой платформы. Для обычной установки используется `scripts/setup_web.ps1` без дополнительных параметров.

Подтверждение теперь требует последовательных наблюдений: пропуск сбрасывает счётчик неподтверждённого кандидата. В событии хранится фактический кадр подтверждения. На панели отображается последнее расстояние, а исторический минимум остаётся только в истории трека.
