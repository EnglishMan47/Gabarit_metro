## Итоговый результат

Локальное веб-приложение одной командой открывает предоставленные `.db3`, показывает облако точек, выделяет опасный коридор и найденные объекты, вычисляет расстояние, воспроизводит запись по кадрам и сохраняет подтверждение либо отклонение тревоги оператором.

Архитектура: браузер → локальный HTTP API → CDR-декодер `PointCloud2` → геометрический детектор → JSON. Приложение не зависит от ROS, Docker, облачных API и загрузки датасета в интернет.

## Приоритеты

### P0 — обязательное рабочее решение

1. Устранить ложные тревоги на штатной инфраструктуре.
2. Стабильно находить человека и отдельный объект в положительном bag.
3. Выдавать расстояние до ближайшей поверхности.
4. Поддержать все шесть записей через веб-интерфейс.
5. Измерить скорость, пропуски и ложные тревоги.
6. Сделать запуск на чистом компьютере понятным из README.

### P1 — демонстрация

- воспроизведение, пауза и покадровый просмотр;
- вид сверху и профиль облака;
- коридор, боксы и карточка ближайшего препятствия;
- статус пути, FPS и задержка;
- подтверждение/отклонение тревоги;
- журнал и экспорт событий.

### P2 — после качества baseline

- полноценная WebGL-сцена;
- интерактивная настройка параметров;
- временные треки объектов;
- синтетические препятствия разных форм;
- экспериментальная обучаемая модель.

## Текущие риски

| Риск | Решение |
|---|---|
| Статические конструкции внутри простого прямого коридора | Модель нормальной сцены, адаптивный коридор, отчёт по каждому типу тоннеля |
| Браузер не справляется с 300–900 тыс. точек | Отдельная выборка для визуализации; детектор работает на более плотных данных |
| Единственный положительный проезд | Не заявлять общую accuracy, разделять реальные и синтетические проверки |
| Низкий объект удаляется вместе с полом | Отдельная ветка сравнения с фоном и контроль объекта 300×300×100 мм |
| Оператор задерживает автоматическую тревогу | Решение детектора публикуется сразу; ответ оператора только журналируется |

Следующее действие: построить модель штатной сцены и прогнать текущий detector API по всем кадрам, чтобы зафиксировать и устранить источники ложных тревог.
