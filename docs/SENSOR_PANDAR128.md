# Pandar128E3X: характеристики, важные для проекта

Источник: `Pandar128E3X_v4p5_User_Manual_128-en-240710-1.pdf`, версия документа `128-en-240710`. Руководство добавлено в проект 19.09.2026. Оно описывает семейство/модификацию сенсора, но не доказывает, что все предоставленные bag записаны ровно с этой конфигурацией.

## Паспортные параметры

По страницам PDF 17–21, разделы 1.3–1.4:

| Параметр | Значение |
|---|---|
| Каналы | 128, углы распределены неравномерно |
| Метод сканирования | Механическое вращение |
| Диапазон | 0,3–200 м при отражении 10% |
| Точность дальности | ±8 см на 0,3–0,5 м; ±5 см на 0,5–1 м; в среднем ±2 см на 1–200 м |
| Горизонтальный обзор | 360° |
| Горизонтальное разрешение | 0,1°/0,2° при 10 Гц; 0,2°/0,4° при 20 Гц |
| Вертикальный обзор | 40°: от −25° до +15° |
| Вертикальное разрешение | 0,125° в центральных каналах, 0,5° и 1° на краях |
| Частота кадров | 10 или 20 Гц |
| Возвраты | First/Last/Strongest; одиночные и двойные комбинации |
| Максимальный поток валидных точек | 3,456 млн/с для single return; 6,912 млн/с для dual return |
| Передача | 1000BASE-T или automotive 1000BASE-T1 |
| Измерения | Дальность, азимут и отражательная способность |

У каждого канала есть собственные горизонтальная и вертикальная угловые поправки. Руководство указывает, что они находятся в correction-файле конкретного сенсора. Текущий вход уже содержит декартовы координаты, поэтому correction-файл нужен только при переходе к сырым UDP-пакетам или проверке калибровки.

## Следствия для алгоритма

- Плотность точек меняется по вертикали и дальности, поэтому фиксированный минимальный размер кластера для всех расстояний ненадёжен.
- Режим возврата влияет на число точек. Детектор не должен определять препятствие по общему размеру сообщения.
- Паспортные ±2 см не являются гарантированной ошибкой итогового расстояния: добавляются ошибка калибровки, кластеризации, видимость поверхности и движение.
- Ближняя зона до 0,3 м не покрывается паспортным диапазоном.
- Заявление о детекции на 300 м должно подтверждаться фактическими данными; руководство гарантирует дальность только до 200 м в указанных условиях.
- Для браузера облако нужно прореживать отдельно. Детектор должен сохранять достаточную плотность для объекта 300×300×100 мм.

## Что остаётся неизвестным

- точная аппаратная модификация и серийный correction-файл сенсора, которым записаны bag;
- режим single/dual return и разрешение конкретных записей;
- установка сенсора относительно пути;
- влияние преобразований, выполненных до записи `PointCloud2`.

Эти параметры нельзя восстанавливать только по названию руководства. Для реализации приоритет имеют фактическая схема и статистика bag.
