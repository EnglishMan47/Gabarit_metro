# Приёмка комплекта 20.09.2026

Статус: рабочий демонстрационный комплект, **не финальная сдача**. Этот документ имеет приоритет над прежними отметками «этап выполнен».

## Проверено

- Установка в чистое окружение Python 3.11.8, NumPy 2.4.6 из локального wheel без сети.
- 21 автоматический тест, включая смешанные темы bag, BEV-признаки и разметку, ONNX fallback, бинарный пакет, неизменность сетки фона при настройке UI, дальний объект, временную последовательность и экспорт.
- Полный прогон 2 488 кадров без ошибок; 140/140 размеченных кадров человека и 201/201 кандидата предмета; второй человек вне габарита — 0 сопоставлений.
- Веб-воспроизведение, пауза, таблица треков, журнал и CSV. Чередование двух HTTP-сессий не смешивает трекеры.
- Полный вычислительный кадр p95 96,70 мс, детектор p95 64,81 мс. Пик рабочего набора по счётчику ОС 113,90 МБ.
- HTTP на 40 кадрах: p95 200,69 мс, 5,25 ответа/с, около 425 КБ/ответ. Это скорость API; визуальная отрисовка браузера может быть медленнее (в проверке около 3,8 FPS).
- Подготовлены архив исходников с SHA-256, содержательный черновик презентации, диагностическая GIF-анимация и сценарий демонстрации.
- Обучена экспериментальная BEV-модель, проверены экспорт ONNX, Windows CUDA/CPU fallback, автоматический выбор backend и Three.js-визуализация. Модель остаётся диагностической из-за отсутствия независимого положительного проезда.

## Критерии, которые не прошли

1. **Ложные тревоги:** 36 устойчивых интервалов на пяти штатных записях. Внутренняя цель 0,5 события/мин не достигнута.
2. **Обобщение:** при исключении `roundT_doubleT` из построения фона тревога есть в 202/252 кадрах. Два длинных интервала не означают хорошее качество; необходимо учитывать длительность тревоги.
3. **Независимая разметка:** нынешняя положительная разметка предварительная и частично построена алгоритмически; 100% на ней нельзя переносить на скрытый тест.
4. **Геометрия и дальность:** прямой резервный коридор и слабое покрытие рельсов не решают все повороты. UI обрабатывает выбранную дальность до 200 м, но качество на этой дальности не подтверждено данными.
5. **Защита:** официальный шаблон презентации пока отсутствует. Черновик не подтверждает соблюдение структуры обязательных слайдов 7–11. GIF — визуализация данных, не запись работы интерфейса; финальное демонстрационное видео ещё необходимо.
6. **Сдача:** публикация, release-тег и загрузка на площадку не выполнены. До этого требуется пройти критерии качества и проверить официальный состав комплекта.

## Что дальше по алгоритму

Текущая модель фона строится в координатах сенсора без регистрации движения. Следующий содержательный шаг — оценка перемещения между кадрами и геометрии протяжённых конструкций вне обрезанного коридора, затем проверка на полностью отложенных проездах. Повышение порогов по уже просмотренным координатам положительных объектов не является допустимой заменой.
